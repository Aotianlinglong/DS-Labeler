## 1. 工程类型

软件按**目录结构**自动判定工程类型：

| 类型 | 数据目录内容 | 工程文件 | 工作数据 |
|---|---|---|---|
| **标准工程** | `wav/` + `TextGrid/`（每句同名） | `<数据目录>/project.json` | `<数据目录>/.dsl/` |
| **翻新工程** | `transcriptions.csv` + `wavs/`（或 `wav/`、根下 `*.wav`） | `<软件根>/refurbish/<名>.refurbish.json` | `<软件根>/refurbish/cache/<工程名>/` |

翻新工程用于处理**已导出**的 DiffSinger 数据集（没有 TextGrid 三层，只有 csv + 音频）：
软件**绝不往数据目录写任何东西**，工程文件与 F0 缓存都放在自己的 `refurbish/` 下。

翻新工程没有 words / texts 层，词 / 短语相关编辑与「按词显示音符标签」不适用，
音符标签退回按元音核心的启发式（见第 3 节）。

软件级设置写在**软件根目录**的 `app_settings.json`（跟随软件而不跟随工程，可用环境变量
`DSL_APP_SETTINGS` 改到别处）。某些目录会由软件自动创建，不必手动准备。

## 2. 使用

1. **工程**：`新建工程…`（Ctrl+N）/ `打开工程…`（Ctrl+O）/ `最近工程`（路径失效则置灰）。
   首次打开需手动选**主语言**；缺失预处理数据的句子自动后台排队（标准工程跑 RMVPE F0 +
   GAME 音符，翻新工程只算 F0），进度在状态栏。
   `保存工程`（Ctrl+S，另有自动保存）。`工具`菜单：`批量预处理` / `重跑当前句` /
   `批量替换音素…` / `计算所有文件口型`（需已放置 R3MOE 权重）。
2. **句子列表**（左栏）：详细信息视图，默认显示`名称` + `质量分`；表头右键可勾选
   `置信度` / `确定性` / `单调性` / `一致性` / `跳过数`（名称列固定）；点表头按该列升 / 降序，
   数值列按数值比较。人工编辑过的句名前带 `✓`，底部进度条显示已标记句数与占比。
3. **音素搜索**（列表上方）：空格分隔多个音素 = **满足任一即显示**；`[z ai]` = 该序列
   **按顺序连续出现**才算命中。音素按本体匹配（忽略语言前缀与大小写）。点放大镜或按 Enter
   执行；点输入框右侧的叉立即清空并恢复完整列表。命中的句进入列表，命中时段在右侧面板常亮。
4. **顶部层信息栏**：显示当前句、时长、音素数 / 音符数，以及选中 / 悬停音素与选中音符的
   起止、时长、音名；同时也是 **words / texts 层的编辑面板**。
5. **面板**：波形、钢琴卷帘（含 F0 曲线）、口型、mel 频谱共享同一时间轴，可用 `QSplitter`
   拖拽调整；`显示`菜单或 设置 →「面板」页可分别开 / 关，顺序可调（默认 **波形 → 钢琴卷帘
   → 口型 → 频谱**，隐藏的面板自动跳过）。口型面板默认关闭，曲线**不可编辑**，顶部画音素
   边界竖线与音素名，纵轴可「按当前句峰值自适应高度」（默认开）。
6. **编辑**：
   - **播放**：空格 = 播放 / 停止。频谱 / 钢琴卷帘窗内**右键**未命中音符处 → 播放该处音素；
     右键**命中音符** → 菜单（设为 / 取消 连音、无声）。
   - **音素层**：**双击**或 `Ctrl+R` 重命名、`Ctrl+D` 复制、`Delete` 删除。
     **拖动边界**自动夹在相邻音素之间（不穿越、不产生零长音素），与边界齐平的音符端点同步跟随；
     SP / AP / br / sil 等无声音素以灰色块渲染，同样可编辑。
   - **words / texts 层**（在层信息栏内）：左键拖条目边界；双击改名，或先点中条目再用
     `Ctrl+R` 重命名 / `Ctrl+D` 复制 / `Delete` 删除（**只有选中条目时快捷键才作用于它**，
     在画布上一点即切回音素 / 音符语义）。复制 = 条目从中点切两半、两块同名；
     删除 = 删掉条目，与前一相邻条目连续时区间并入前一条目。
   - **音符**：拖动改音高（自由，保留音分）、拖两端改时间（吸附音素边界）、双击切分。
     **切分瞬间**用音高判定把前后两半对齐到实际人声：优先直接读已加载的 F0 曲线（不读音频），
     该句无 F0 缓存时按音频现场判定；只执行这一次并随切分一起进撤销，之后仍可手动改音高。
7. **层间联动**（只向上）：拖 **phones** 边界时，words / texts 里**同时间对齐**的边界一起移动；
   拖 **words** 边界时 texts 对齐边跟随、**不动 phones**；拖 **texts** 边界不联动。
   夹取范围取各层交集，联动后三层仍严格对齐。**拖动吸附**：拖 words 边界靠近 phones 边界
   （容差 6 像素）即吸附到位，拖 texts 边界可吸 words 与 phones 边界 —— 吸附**只改落点，
   下层永不被拖走**。
8. **word 名自动更新**：该 word 下音素**增减或改名**时，名字改写为音素原名集合
   （如 `wo` → `zh/w zh/uo vf`）；音素没变则**保持源标记原样**。翻新工程无 words 层，不涉及。
9. **缩放 / 滚动**：滚轮 = 上下滚动、`Shift+滚轮` = 水平滚动、`Ctrl+滚轮` = 时间轴缩放
   （以光标为中心）、`Alt+滚轮` = 音高方向缩放；中键拖动 = 平移画布；`Z` = 适配全曲。
   视图菜单另有 `放大` / `缩小` / `面板均分` / `频谱配色`。
10. **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`）。所有编辑（含层边界拖动、
    改名、复制、删除）都是一条可撤销命令。
11. **导出**：`导出数据集…` 弹窗填**音色名称**（必填，记进工程、下次预填），输出
    `<所选文件夹>/<音色名>/raw/wavs/*.wav` + `<所选文件夹>/<音色名>/raw/transcriptions.csv`。
    翻新工程为 `导出 CSV…`。
12. **回写 TextGrid**（标准工程，手动触发）：把编辑后的 **phones / words / texts 三层**
    覆盖写回源 TG。
13. **设置**（`设置`菜单，软件级，跨工程共用）：语言（主语言、全局无声音素）/
    频谱（窗函数、配色、频率标度等）/ 波形（音符组下的波形）/ 面板（显隐与顺序、标签字号）/
    配色（界面配色方案，含自定义，另有音素搜索高亮色）。改动即时生效。
14. **帮助** → `关于 / 快捷键`（快捷键一览）。

## 3. 音符标签规则

显示在**音符块外上方**；块内是否再写一份由 设置 →「面板」页「在音符块内显示标签文字」控制，**默认关闭**。

- **有 words 层时**（标准工程）：标签 = 该音符**起点所在 word** 下的**音素集合**
  （如 `w uo`；音素只显示**本体、不带语言前缀**，`en/d en/ow en/n` → `d ow n`）。
  合规 TG 下一个 word 只对应一个非连音音符；若出现第 2、3 个非连音音符则**留空**。
  音素归属按**起点**判定，因此拉长音素不会改变归属。
- **无 words 层时**（翻新工程）：启发式 = `起音辅音 + 元音核心 + 到下一音节起音之前的音素`
  （元音核心 = 与该音符重叠时长最大的那个元音；相邻音节区间首尾相接 → 同一音素只显示一次）。
- 休止一律写 `R`，连音（slur）一律写 `-`。

## 4. 音素词典（可直接编辑）

音素分类（元音 / 辅音 / 流音 / 全局无声音素）**不写死在代码里**，唯一事实源是
`assets/dictionaries/<语言>/` 下的 txt，每个文件一行、空格分隔：

| 文件 | 含义 |
|---|---|
| `vowels.txt` | 元音（含 `SP` / `AP` 这类按韵母处理的符号） |
| `consonants.txt` | 辅音 / 声母 |
| `liquids.txt` | 流音（多音节系统用，目前仅 en：`_r l r w y`） |

内置 `zh` / `ja` / `en` / `yue` 四套。

- **加音素**：写进对应语言的 `vowels.txt` / `consonants.txt` 即可（空格分隔）。
- **删 / 改名**：直接改 txt；不在表里的音素会被标成 `unknown`，导入时高亮提示。
- 语言前缀 `en/` / `yue/` … 按对应语言的表分类；无前缀按**工程主语言**的表分类。
- 文件不存在 = 该表为空，不报错（所以 `zh` / `ja` 没有 `liquids.txt` 也正常）。

> 这些词典是**普通数据文件**，按数据集 / 音素体系自行替换即可，不需要改代码。
